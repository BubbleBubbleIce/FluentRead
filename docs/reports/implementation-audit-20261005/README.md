| API key 租约 | 完成每个租约都扫描全部在途租约；手动验证成功后冷却时间未清理 | 2,000 租约的回收不遍历 active leases；重复结束不减错计数；成功清除冷却 |

| 页面上下文捕获 | TreeWalker 不检查根自身或根外祖先，超大可编辑、表单或扩展 UI 根可能进入摘要 | 大根、隐藏祖先、表单祖先和扩展所有权场景均排除 |
| 多次变动 → 安静窗口 | 补充持续变化的压力验证 | 500 次、16ms 间隔变化期间只有一个 timer，无请求；稳定后只调度最新来源一次 |

删除已确认没有生产、构建或公开调用的文档预览元信息、格式配色与选中模型标签函数，以及区域快捷键中重复的输入焦点判断。批量协议已经校验为等长稠密字符串数组的路径删除冗余空串兜底。两条旧测试通过改写 `Array.prototype` 和内部数组 getter 制造校验后缺项，且预期返回 `undefined`；这些实现细节用例已移除，真实 provider 错误形状、缺项、空槽、协议重复标记和消息外部修改测试继续保留。

测试基线中的图片术语并发夹具按未保护原文分派，但统一 broker 实际发送占位符，导致两个既有失败。已用基线 broker 复现，并改为读取请求中的原始语言检测样本；没有绕开术语保护。另修正了两处与当前划词设置路由及 UI 滚轮策略不一致的旧架构断言，并生成缺失的五份 userscript 语言资源。
