## 第二批：整批重挂与布局检查

旧的同边界匹配为每个旧 owner 遍历全部新增根，500 段独立或同文段落会读取 250,000 次可信模板 HTML。现在按相对路径、范围和结构建立共享候选组，线性汇总输出差异与配对歧义；工作量用例要求模板读取不超过 3,000 次。不同译文的同文列表、跨路径候选汇合、溢出身份、宿主篡改与熔断继续保守处理。

浏览器暴露了工作量计数之外的阻塞：逐段 append 与尺寸读取交错时，整批重挂有约 350–390ms 长任务。改为先检查全部候选、再统一挂载、最后核对布局；在每项提交前再次检查来源，单项布局失败独立回滚。布局读数只在同一同步批次复用，任何覆盖样式写入后立即失效；同批 500 段的共享 main transform 读取降至一次。布局入口的纯转发函数改为直接重导出。

另修复 getter 消息字段在入口重复读取或形成非法属性描述符的问题。协议解析先复制标记数组，再利用已经验证的“非空且各出现一次”契约，删除冗余缺项和重复起始标记扫描；结束标记交错仍整包拒绝。

40 个针对性测试文件、1,243 个用例通过；`bilingualRemount`、`bilingualRemountMatching`、`requestSnapshot`、`serialization`、`layoutMeasurements` 五个模块四项覆盖率均为 100%。类型检查、Chrome 与 Firefox 生产构建、userscript 构建与 verifier、文档构建与检查均通过；两个受影响架构文件的 101 个用例通过。新增布局测试已归入测试矩阵，套件审计通过。浏览器关闭后再次确认临时测试进程为零。

最新生产构建的 500 段独立原文与同文两种场景均连续重挂三次：下一帧前接管全部 500 个精确译文，没有嵌套或新增上游原文，宿主点击可响应，恢复和缓存重译通过。同文场景只有两个上游条目（正文及标题）。首次翻译、滚动、恢复、缓存重译没有 >50ms 长任务；**整批重挂仍有 162–173ms 长任务，性能目标未完成**。共享读数虽减少重复工作，当前浏览器运行未证明它进一步降低整批耗时。

这些运行使用同一受控 fixture，但没有安静环境中的完整基线成对复测；不据此声称整体加速比例。仍需将大批接管的同步工作量限制在可响应的时间片，并验证首屏稳定与离屏结果复用。

## 第三批：文本槽协议

复现了跨槽标记碰撞：第一槽含有第二槽的完整起止标记时，旧编码只检查第一槽自己的标记，导致自己生成的请求包解析失败并触发逐槽回退。现在同一 nonce 的任一实际槽标记出现在任一来源中都会避让；超范围编号和非标准数字仍作为字面内容保留。

标准内部协议改为一次前向标记扫描，按顺序检查缺项、重复、交错及包外正文。零宽扫描显式前进，检测共享末尾下划线的标记，并保留原协议对同一标记的非重叠计数。对两槽包每个位置插入各标记、删除标记及共享下划线的变化，结果与原字面协议一致。公开类型所允许的非标准自定义标记继续使用兼容解析。纯文本协议移入 `slotProtocol.ts`，DOM 序列化直接重导出，调用入口不变。

44 个相关测试文件、1,327 个用例通过，`serialization` 和 `slotProtocol` 四项严格覆盖率均为 100%。类型检查、Chrome/Firefox 生产构建、userscript 构建与 verifier、测试套件审计、文档构建与检查，以及两个受影响架构文件的 19 个用例通过。

Node 20.11.1 同进程交替微基准：500 槽、365,669 字符，预热后每版 20 个样本，每个样本解析五次并检查结果；旧版中位 91.39ms，新版 2.28ms。仅说明这个标准协议 fixture 的解析耗时，不是浏览器或真实服务基准；第二批整批 DOM 重挂的 162–173ms 长任务仍待处理。该批还记录了全文请求入口中微任务合批与异步回填持有调用者数组的风险，后续由第四批复现修复。

## 第四批：全文请求与回退快照

复现三个异步错配：AI 微任务合批前修改来源数组会发送编辑后及注入文本，配置改动会改变模型、目标语言与术语，并污染原身份缓存；provider 等待期间修改数组会改变已经跳过的原文槽并返回额外项；整段请求无有效结果后，逐槽回退会读取外部新配置。现在在请求入口复制来源和配置数组，并为整个正文请求/回退捕获同一配置。类型和复制规则集中到无存储或 DOM 依赖的 `translationConfigSnapshot.ts`，保留旧类型导出入口。

本地 auto 模型逐槽请求原来为每个槽重新 `join` 全段来源，200 槽重复构造 200 次相同语言样本。现在只构造一次，所有工作者仍使用相同检测文本。删除稳定非空请求边界后的冗余空数组兜底；原来将清空外部数组当成取消的测试改为验证入口快照，真实 AbortSignal 取消、共享请求回收、失败与重试用例保留。

44 个相关测试文件、1,331 个用例通过。`translationRequest`、`liveTextTranslation`、`translationConfigSnapshot` 三个模块四项严格覆盖率均为 100%；类型检查、Chrome/Firefox 生产构建、userscript 构建与 verifier、测试套件审计、文档构建与检查，以及两个受影响架构文件的 19 个用例通过。

最新生产构建的 500 段独立原文复测通过：三轮重挂在下一帧前保持全部精确译文，无嵌套、无额外上游原文；总计仍为 501 个条目，中文原文零请求。首次翻译、滚动、恢复与缓存重译均没有 >50ms 长任务，心跳最大间隔约 36ms。**整批重挂仍有 174–187ms 长任务，性能目标继续未完成**；这次运行不用于估算整体加速或回归比例。截图已查看，隔离浏览器关闭后确认临时测试进程为零。
